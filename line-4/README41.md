# The Fork That Chooses — record 41

[Event Filter](tools/event-filter/README.md) adds an offline way to prepare
`eth_getLogs` topic filters from ABI values. Exact values, OR alternatives and
wildcards retain their topic positions. Indexed strings, bytes, supported scalar
arrays and nested tuples use Solidity's special in-place encoding before
Keccak hashing. No network request is sent. The ZTO-first demo uses the real
token address and a retained historical block, without claiming a transfer.

```sh
python3 -B line-4/tools/event-filter/event_filter.py --demo
```

All 18 new tests and 13 Event Lens dependency tests passed. Independent byte
layouts, known Keccak vectors, position preservation, ambiguous indexed
preimages, malformed inputs, CLI error behavior and aggregate limits are
covered. [Check evidence](checks41.json) records the commands and results.
The supplied ABI and target remain unauthenticated. Unsupported schemas and
anonymous events are refused; full ABI support is outside this piece's scope.
